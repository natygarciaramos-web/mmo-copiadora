# MMO Copiadora

Site institucional desenvolvido para apresentar a MMO Copiadora e divulgar seus serviços gráficos.

## Serviços apresentados

- Cópias e impressões.
- Digitalização de documentos.
- Plastificação.
- Plotagens.
- Produtos personalizados.
- Cartões de visita.

## Tecnologias

- React
- JavaScript
- CSS
- Vite
- Hospedagem na Netlify

## Executar localmente

Com o Node.js instalado, execute:

```bash
npm install
npm run dev
```
